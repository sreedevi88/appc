# KML to CSV Converter

## Overview

KML to CSV Converter is an automation tool that converts KML files into CSV format.

## Features

* Upload KML files
* Extract location and coordinate data
* Convert KML data to CSV format
* Tamil to Tanglish place name conversion

## Technologies Used

* Python
* Streamlit
* XML ElementTree
* CSV

## How to Run

1. Install dependencies

pip install -r requirements.txt

2. Run the application

python -m streamlit run appc.py
